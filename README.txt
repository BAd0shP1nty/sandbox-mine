VOXEL CRAFT SANDBOX
===================

Windows quick start
1. Extract Voxel_Craft_Sandbox.zip to a folder.
2. Open index.html in current Chrome or Edge.
3. Click ENTER WORLD. Move with WASD, look with the mouse.
4. Left-click to mine, right-click to place a block, keys 1-5 to choose a block.
5. Press ESC to release the mouse. Click ENTER WORLD to resume.

Notes
- This is an original, small voxel-building prototype, inspired by the genre rather than copied Minecraft code/assets.
- Internet access is needed when opening the game because Three.js is loaded from jsDelivr CDN.
- If your browser blocks local file scripts or WebGL, try Chrome/Edge and ensure hardware acceleration is enabled.
- MVP limitations: no save/load yet, no crafting, no mobs, and simple collision/terrain.
